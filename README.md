# Clip

Mac 剪切板管理器，交互参考 [Paste](https://pasteapp.io/)：底部卡片条、分组（Pinboard）、搜索、本地保存。没有账户，也没有登录。

## 使用

1. 运行 `./Scripts/build.sh`
2. 打开 `dist/Clip.app`
3. 用 **⇧⌘V** 或菜单栏图标唤出窗口
4. 复制任意内容后会出现在卡片条里，回车粘贴

首次使用建议在系统设置里授予 **辅助功能** 权限，这样选中卡片后会直接粘贴到当前应用。不授权也可以，内容会先写入系统剪切板。

如果你已经安装了官方 Paste，它也占用 ⇧⌘V。使用 Clip 时请先退出 Paste，或在 Clip 设置里改用菜单栏图标唤出。

## 快捷键

默认与 Paste 接近，可在 **设置 → 快捷键** 里点按后改成自己的组合。全局唤出需要带 ⌘ / ⌥ / ⌃。

| 默认 | 功能 |
| --- | --- |
| ⇧⌘V | 显示 / 隐藏 |
| ⌘T | 暂停记录 |
| ← → | 切换卡片 |
| ↩ | 粘贴 |
| ⇧↩ | 粘贴为纯文本 |
| ⌘1–9 | 快速粘贴 |
| Space | 预览 |

## 隐私

历史只存在本机 `~/Library/Application Support/Clip/`。可在设置里忽略密码管理器等应用，或临时暂停记录。
